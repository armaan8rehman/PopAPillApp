# 💊 Pop-A-Pill – Medication Reminder App

## Overview
Pop-A-Pill is an iOS application built with Swift that helps users manage their medication routines. It provides daily reminders, medication tracking, and a user-friendly interface to promote adherence and health awareness.

## Features
- Add and manage medications with dosage and time
- Set smart reminders
- Track medication history
- Automatic notification support

## Technologies Used
- Swift
- Xcode
